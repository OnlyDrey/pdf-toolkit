# Accessibility, VersionFix and branding review

## Audit and implementation plan — 2026-11-01

Reviewed all seven PDF tools, shared buttons/inputs/selects/tabs, navigation, session toolbar, file drop zones, PDF previews, processing/error/success feedback, theme tokens, localization, favicon and browser tests. No screenshot files accompanied the request; the described tab borders/discard contrast are investigated against local captures. The existing compact layout and browser-only PDF processing remain the baseline.

| Severity   | Component/finding                                                                                               | WCAG 2.2                              | Correction                                                                                                       |
| ---------- | --------------------------------------------------------------------------------------------------------------- | ------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| High       | Rotate and Resize reuse `ps`; mounted hidden panels can steal label associations                                | 1.3.1, 3.3.2, 4.1.2                   | Unique tool-prefixed IDs and feedback descriptions                                                               |

| Medium     | Focus varies across buttons, theme switches, file drop zones and selects; tab rings clip in horizontal overflow | 2.4.7, 2.4.11                         | Shared focus-visible treatment, inset tab indicator, no pointer-focus ring/layout shift                          |
| Medium     | Reorder/remove icons are 16px bare controls; checkboxes have small hit areas                                    | 2.5.8                                 | Expand targets/associated labels without expanding the overall page layout                                       |

Plan: (1) commit this audit; (2) implement/test header-only VersionFix and evaluate real conversion; (3) export canonical branding assets; (4) remediate shared focus, navigation, feedback, forms and toolbar; (5) add axe/keyboard/state coverage; (6) perform full regression, visual inspection and Docker/static-asset checks, then record limitations. Commit/push each completed phase only to work with skip-ci commits. No Actions dispatch, release publication or main modification.

Automated tests will target WCAG 2.2 AA, but cannot establish full compliance. Manual assistive-technology review, content alternatives for user PDFs, cross-browser rendering and PDF compatibility validation remain separate evidence requirements.
